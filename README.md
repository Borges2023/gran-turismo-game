# Gran Turismo Game

Projeto convertido para HTML, CSS e JavaScript puros.
Este e um jogo de corrida estatico que pode ser aberto diretamente no navegador.

## Como executar localmente

1. Abra o link https://borges2023.github.io/gran-turismo-game/ no navegador.
2. Use as setas <- e -> para mover o carro.
3. Pressione Espaco para ativar o nitro.

## Estrutura do projeto

- `index.html` - pagina principal do jogo.
- `styles.css` - estilos visuais.
- `script.js` - logica do jogo e controles.
- `public/` - imagens e sons utilizados pelo jogo.

## Como publicar no GitHub Pages

1. Envie o projeto para o GitHub.
2. E segue a estrutura do GitHub.

## Observacoes

O jogo agora roda totalmente no navegador sem dependencias do Next.js ou React.
